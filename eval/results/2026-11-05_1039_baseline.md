**[comparison · Piyush Garg] What is the difference between episodic and semantic memory in Piyush's agent memory video?**  
<sub>status supported · 1.8 s · correctness=1 relevance=1 groundedness=1 retrieval=1 video_moment=1</sub>

> Episodic memory is described as the patterns about past interactions, which includes specific events and experiences, such as what someone did yesterday or on a particular date. It is a growing list of past events that does not override previous memories. In contrast, semantic memory is characterized as a vector memory that contains general knowledge and facts, which also remains a growing list. Thus, the key difference is that episodic memory relates to personal experiences and specific events, while semantic memory pertains to general knowledge and information.
