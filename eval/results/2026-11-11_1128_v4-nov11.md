**[comparison · Edureka] How does agentic RAG differ from normal RAG?**  
<sub>status supported · 2.1 s · correctness=1 relevance=1 groundedness=1 retrieval=1 video_moment=0</sub>

> Agentic RAG differs from traditional RAG in that it treats each query as a multi-stage mission. In agentic RAG, a planning agent breaks down the question into discrete tasks, while retrieval agents access multiple systems for data. This allows for real-time adaptation and validation of information, ensuring accuracy before generating a response. Traditional RAG, on the other hand, simply retrieves relevant documents and passes them to the LLM for response generation without the ability to adapt or validate in real-time.

<sub>status supported · 1.9 s · correctness=1 relevance=1 groundedness=1 retrieval=1 video_moment=1</sub>

> Episodic memory refers to the patterns of past interactions and events, such as remembering specific occurrences like a date or an event that happened yesterday. In contrast, semantic memory is described as a vector memory that contains general knowledge and facts, which also remains a growing list but focuses on factual information rather than personal experiences.
