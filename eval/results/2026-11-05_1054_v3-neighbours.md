> Episodic memory is described as the patterns about past interactions, essentially a growing list of past events and experiences. For example, it includes specific instances like what someone did yesterday or on a particular date. In contrast, semantic memory is characterized as a vector memory that contains general knowledge and facts, which also remains a growing list. Thus, the key difference is that episodic memory relates to personal experiences and specific events, while semantic memory pertains to general knowledge and information.
