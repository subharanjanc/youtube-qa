<sub>status supported · 2.3 s · correctness=1 relevance=1 groundedness=1 retrieval=1 video_moment=1</sub>

> Embeddings are a process of converting text into a vector such that it can represent its meaning. All the chunks of text are converted into vector embeddings, which are then stored in a vector database. This is different from a regular database, which can search using exact values. In contrast, a vector database can search using the meaning of the text. For example, when searching for a company that is a leader in electric vehicles, a vector database will return results based on the meaning, such as Tesla, rather than exact word matches.

In contrast, semantic memory is characterized as a vector memory that contains general knowledge and facts, which also remains a growing list.
